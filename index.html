API Key Tester

Teste einen API-Key gegen eine API, ohne den Key im Quellcode zu speichern.

Anfrage

Der Key wird nicht im GitHub-Code gespeichert.

Wichtig: Eine GitHub-Pages-Seite kann API-Keys grundsätzlich nicht geheim halten. Außerdem kann die API den Browserzugriff wegen CORS blockieren. Für einen echten geheimen Key ist ein Server/Backend besser geeignet.
