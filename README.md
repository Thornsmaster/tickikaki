# TickiKaki

Tic-Tac-Toe mit Passwort-Login und Admin-Modus.

## Passwörter

- Normaler Spieler: `132`
- Admin: `maio`

Es wird **kein Benutzername** benötigt.

## GitHub Pages

1. Repository öffnen.
2. **Settings → Pages** öffnen.
3. Bei **Build and deployment**: **Deploy from a branch** auswählen.
4. Branch **main** und Ordner **/(root)** auswählen.
5. **Save** drücken.

## Sicherheit

Diese Version ist eine einfache Demo für GitHub Pages. Die Passwörter stehen im JavaScript-Code und sind deshalb im Browser einsehbar. Für eine echte öffentliche Anwendung sollte die Authentifizierung serverseitig umgesetzt werden.
